GITHUB PROFILE README - UPLOAD GUIDE

1. Create/open your GitHub profile repository:
   https://github.com/kashaboinashalini
   The repository name must be exactly: kashaboinashalini

2. Upload all files from this folder to that repository:
   README.md
   .github/workflows/profile-stats-snake.yml
   profile/

3. Commit the changes.

4. Open the repository's Actions tab and run "Update GitHub Profile" once
   using "Run workflow".

5. After the workflow finishes, open your GitHub profile.
   The README should appear automatically.

Note:
- The original creator's profile photo was intentionally not copied.
- No email address was added because you did not provide one.
- GitHub stats/snake SVGs are regenerated by the workflow.
